## API surface — read this first

ACCURE has NO public API. There is no developer portal, no API reference, no OpenAPI or
other machine-readable contract, no SDK on any package registry, no CLI, no MCP server, no
A2A agent card, no public sandbox and no published rate limits or pricing.

The product API that exists is customer-only:

- Platform (human): https://accure-platform.com — an Auth0-protected single-page
  application. This is the "Login" link on accure.net.
- API gateway: https://gateway.accure-platform.com — established by probe, not by
  documentation. The platform bundle declares this URL as its Auth0 API audience. Anonymous
  requests receive an nginx HTTP 403 at the edge, or a Fastify JSON 404 envelope on routes
  that reach the application. Every route requires an Auth0-issued bearer token.
- Authorization server: https://production-accure.eu.auth0.com — ACCURE's own Auth0
  tenant. Its OpenID Provider metadata IS served anonymously and is the one machine-readable
  document ACCURE publishes.

ACCURE states on its product page that the platform provides "open REST and OPC-UA
interfaces", SFTP and API endpoints for historical BMS logs, single sign-on and webhooks.
None of that is documented publicly; it is a claim on a marketing page, not a contract.
